## **Descrição:** 
Nesta atividade, montamos um circuito no Tinkercad usando um Arduino, um sensor de presença (PIR) e um LED. O sensor identifica quando há movimento no ambiente e envia essa informação para o Arduino. Quando um movimento é detectado, o LED acende. Quando não há movimento, o LED permanece apagado.
